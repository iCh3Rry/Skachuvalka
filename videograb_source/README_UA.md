# VideoGrab — завантажувач відео з YouTube

**VideoGrab** — кросплатформна десктопна програма (Windows, macOS, Linux) для
завантаження відео та аудіо з YouTube та інших сайтів, що підтримує
[yt-dlp](https://github.com/yt-dlp/yt-dlp). У програму вбудовано два рівні
оновлень:

| Механізм | Що оновлює | Як працює |
|---|---|---|
| Самооновлення програми («по повітрю») | Саму програму VideoGrab | Вбудований плагін Tauri v2 Updater: при натисканні **«Оновити програму»** програма звертається до вашого сервера, порівнює версії, перевіряє підпис і встановлює нову версію з перезапуском |
| Перевірка оновлень yt-dlp | Вбудований yt-dlp | При кожному запуску програма опитує GitHub API yt-dlp; якщо доступна новіша версія, поруч зі статусом з'являється посилання-пропозиція встановити її |

## Як це працює

Програма побудована на [Tauri v2](https://v2.tauri.app) — Rust + нативний
WebView — тому вона маленька (~90 MB разом із yt-dlp), не потребує
встановлення Node.js/Python на комп'ютері користувача і працює однаково на
Windows, macOS і Linux з одного коду.

Файли проєкту:

| Шлях | Призначення |
|---|---|
| `videograb/` | Код програми (Rust у `src-tauri/src/`, інтерфейс у `src/`) |
| `videograb/.github/workflows/build.yml` | GitHub Actions для автоскладання Windows/macOS |
| `deploy/update-server/` | Шаблон сервера оновлень і генератор `latest.json` |
| `sign/key.rsa` | Приватний ключ підпису оновлень (тримати в таємниці!) |

Потік завантаження: користувач вставляє посилання → обирає відео/аудіо,
якість і папку → програма запускає вбудований yt-dlp як ізольований
процес (з очищеним оточенням, щоб уникнути конфліктів з інсталяторами
AppImage) → парсить рядки прогресу `[download]` і показує відсотки та
швидкість у черзі завантажень.

## Запуск з бінарника (Linux)

```bash
chmod +x VideoGrab_1.0.0_amd64.AppImage
./VideoGrab_1.0.0_amd64.AppImage
```

yt-dlp вбудовано в програму. При першому запуску він копіюється в
`~/.local/share/com.videograb.app/videograb/`; якщо вбудованої копії немає
— автоматично завантажується свіжий бінарник з GitHub. Файли за
замовчуванням зберігаються в `~/Downloads`.

Для Windows і macOS дивіться розділ
[«Автоматична збірка»](#автоматична-збірка-для-windows-і-macos) — інсталятор
NSIS (`.exe`) і образ DMG (`.dmg`) створюються на GitHub Actions
(у цій пісочниці можна зібрати лише Linux).

## Збірка на власному ПК

Передумови (один раз):

| Компонент | Windows | macOS | Linux |
|---|---|---|---|
| [Rust](https://rustup.rs) | `rustup-init.exe` | `curl ... \| sh` | `curl ... \| sh` |
| [Node.js 22+](https://nodejs.org) | інсталятор | інсталятор | з пакетного менеджера |
| [pnpm](https://pnpm.io) | `corepack enable` | `corepack enable` | `corepack enable` |
| Залежності Tauri | Visual Studio Build Tools | Xcode Command Line Tools | `build-essential`, `webkit2gtk`, `libappindicator`, `librsvg` (див. [документацію](https://v2.tauri.app/start/prerequisites/)) |

Збірка:

```bash
cd videograb
pnpm install
pnpm exec tauri add updater dialog process opener   # плагіни
# завантажте yt-dlp у src-tauri/resources/
#   Windows: https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp.exe
#   macOS:   .../yt-dlp_macos
#   Linux:   .../yt-dlp
cp /шлях/до/yt-dlp src-tauri/resources/yt-dlp-bundled
pnpm tauri build
```

Артефакти з'являться в `src-tauri/target/release/bundle/`
(`nsis/` для Windows, `dmg/` для macOS, `appimage/` і `deb/` для Linux)
разом із `.sig`-підписами.

## Розповсюдження оновлень по повітрю

Механізм базується на офіційному [плагіні Updater](https://v2.tauri.app/plugin/updater/)
Tauri v2. Кожна збірка підписується ключем `sign/key.rsa`; клієнт зберігає
лише публічний ключ і відмовиться встановлювати непідписаний артефакт.

### Кроки випуску оновлення

1. Змініть `version` у `videograb/src-tauri/tauri.conf.json` (наприклад,
   `1.0.1`).
2. Зберіть артефакти (локально або через GitHub Actions — див. наступний
   розділ).
3. Скопіюйте **всі** артефакти і їхні `.sig`-файли в
   `deploy/update-server/artifacts/<версія>/`.
4. Згенеруйте файл оновлень:

   ```bash
   cd deploy/update-server
   node generate-latest.mjs artifacts/1.0.1 latest.json "Що нового в 1.0.1"
   ```

5. Завантажте `latest.json` і артефакти на ваш HTTPS-сервер за URL-адресою,
   вказаною в `endpoints` файлу `tauri.conf.json`.

Детальний опис і готовий Node.js-сервер — у
`deploy/update-server/README.md`. Найпростіший безкоштовний варіант
хостингу — **GitHub Releases**: додайте `latest.json` і артефакти як ассети
релізу, а в `endpoints` вкажіть
`https://github.com/<ваш-логін>/video-releases/releases/latest/download/latest.json`.

Користувачі отримують оновлення одним кліком по кнопці
**«Оновити програму»**: програма завантажує нову версію, встановлює її
пасивно (Windows) і перезапускається.

## Автоматична збірка для Windows і macOS

У репозиторії є воркфлоу `.github/workflows/build.yml`. Створіть
**приватний** GitHub-репозиторій із кодом `videograb/`, додайте секрети:

| Секрет | Значення |
|---|---|
| `SIGNING_KEY` | вміст `videograb/sign/key.rsa` |
| `SIGNING_KEY_PASSWORD` | пароль `keypass` (змініть на свій у `.env`) |
| `APPLE_CERTIFICATE`, `APPLE_CERTIFICATE_PASSWORD`, `APPLE_SIGNING_IDENTITY`, `APPLE_ID`, `APPLE_TEAM_ID`, `APPLE_PASSWORD` | для підписаного DMG (необов'язково — без них збірка пройде, але macOS вимагатиме натиснути «Відкрити» у сповіщенні Gatekeeper) |

Після публікації релізу (тег виду `v1.0.1`) воркфлоу автоматично
збирає NSIS/MSI-інсталятор для Windows і універсальний DMG для macOS
(Intel + Apple Silicon) і додає їх разом із підписами до релізу. Далі —
скопіюйте артефакти на сервер оновлень за процедурою з попереднього
розділу.

## Ключі підпису та безпека

Приватний ключ оновлень лежить у `videograb/sign/key.rsa`, публічний —
у `tauri.conf.json` (`plugins.updater.pubkey`). Правила:

- **Ніколи не публікуйте `sign/key.rsa`** у відкритому репозиторії —
  додайте `sign/` до `.gitignore` і тримайте копію в надійному місці.
  Будь-хто з цим ключем зможе підписати й поширити шкідливе «оновлення».
- Пароль до ключа задається у `.env`
  (`TAURI_SIGNING_PRIVATE_KEY_PASSWORD`); за замовчуванням — `keypass`.
- Якщо ключ втрачено — згенеруйте новий (`pnpm tauri signer generate`),
  впишіть новий публічний ключ у `tauri.conf.json` і пересоберіть усі
  програми. Старі клієнти з іншим публічним ключем не зможуть отримати
  оновлення, тому важливо одразу розіслати їм свіжу збірку.

Оновлення yt-dlp не підписується власним ключем — yt-dlp завантажується
напрямую з офіційного релізу GitHub (`yt-dlp/yt-dlp`), що дає ті самі
гарантії цілісності.

## Часті питання

**Чому програма пропонує оновити yt-dlp при кожному запуску?**
Програма порівнює вбудовану версію з останнім релізом на GitHub.
Посилання-пропозиція з'являється лише якщо є новіша версія. yt-dlp
виходить щотижня, тому пропозиції часті — встановлення займає кілька
секунд і не вимагає перезапуску програми.

**YouTube блокує завантаження з мого сервера/провайдера?**
yt-dlp підтримує сотні сайтів; якщо конкретне відео недоступне (регіональні
обмеження, приватність), програма покаже помилку в черзі. На власних ПК
користувачів завантаження працює звичайно — обмеження датацентра не
стосуються домашніх мереж.

**Можна вимкнути автоперевірку yt-dlp?**
Так — кнопка **set_auto_check** зберігається у стані сесії; у UI є перемикач.
Перевірку програми можна виконати будь-коли вручну кнопкою «Оновити
програму».

**Що робити, якщо сервер оновлень недоступний?**
Програма продовжує працювати — помилка перевірки лише виводить повідомлення
у рядку стану. Кнопка **«Оновити yt-dlp»** завжди працює напряму з GitHub.
